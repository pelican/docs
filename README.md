# Pelican Docs

> Formerly `pelican-dev/docs`. The GitHub org was renamed to `pelican`, so you're in the right place.

The source for the documentation at [pelican.dev/docs](https://pelican.dev/docs), covering [Pelican Panel](https://github.com/pelican/panel) and [Wings](https://github.com/pelican/wings).

Pelican docs are created with [Docusaurus](https://docusaurus.io).

## Building

To test changes locally install the dependencies and run the server using pnpm.

```shell
pnpm i
pnpm run start
```
