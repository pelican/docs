## Panel Information

Displays the application, database, email and backup configurations along with the panel version.
```sh
php artisan p:info
```

## User Commands
### Create a User

Creates a user on the system via the CLI.
```sh
php artisan p:user:make [options]
```

```sh
Options:
      --email[=EMAIL]
      --username[=USERNAME]
      --password[=PASSWORD]
      --admin[=ADMIN]
      --no-password
  -q, --quiet                Do not output any message
  -V, --version              Display this application version
      --ansi|--no-ansi       Force (or disable --no-ansi) ANSI output
  -n, --no-interaction       Do not ask any interactive question
```

### Delete a User

Deletes a user from the Panel if no servers are attached to their account.
```sh
php artisan p:user:delete [options]
```

```sh
Options:
      --user[=USER]
  -q, --quiet           Do not output any message
      --ansi|--no-ansi  Force (or disable --no-ansi) ANSI output
  -n, --no-interaction  Do not ask any interactive question
```

### Disable 2fa for a single User

Disable two-factor authentication for a specific user in the Panel.
```sh
php artisan p:user:disable2fa [options]
```

```sh
Options:
      --email[=EMAIL]   The email of the user to disable 2-Factor for.
  -q, --quiet           Do not output any message
      --ansi|--no-ansi  Force (or disable --no-ansi) ANSI output
  -n, --no-interaction  Do not ask any interactive question

```

## Node Commands
### Create a Node

Creates a new node on the system via the CLI.
```sh
php artisan p:node:make [options]
```

```sh
Options:
      --name[=NAME]                                    A name to identify the node.
      --description[=DESCRIPTION]                      A description to identify the node.
      --locationId[=LOCATIONID]                        A valid locationId.
      --fqdn[=FQDN]                                    The domain name (e.g node.example.com) to be used for connecting to the daemon. An IP address may only be used if you are not using SSL for this node.
      --public[=PUBLIC]                                Should the node be public or private? (public=1 / private=0).
      --scheme[=SCHEME]                                Which scheme should be used? (Enable SSL=https / Disable SSL=http).
      --proxy[=PROXY]                                  Is the daemon behind a proxy? (Yes=1 / No=0).
      --maintenance[=MAINTENANCE]                      Should maintenance mode be enabled? (Enable Maintenance mode=1 / Disable Maintenance mode=0).
      --maxMemory[=MAXMEMORY]                          Set the max memory amount.
      --overallocateMemory[=OVERALLOCATEMEMORY]        Enter the amount of ram to overallocate (% or -1 to overallocate the maximum).
      --maxDisk[=MAXDISK]                              Set the max disk amount.
      --overallocateDisk[=OVERALLOCATEDISK]            Enter the amount of disk to overallocate (% or -1 to overallocate the maximum).
      --maxCpu[=MAXCPU]                                Set the max cpu amount.
      --overallocateCpu[=OVERALLOCATECPU]              Enter the amount of cpu to overallocate (% or -1 to overallocate the maximum).
      --uploadSize[=UPLOADSIZE]                        Enter the maximum upload filesize.
      --daemonListeningPort[=DAEMONLISTENINGPORT]      Enter the daemon listening port.
      --daemonConnectingPort[=DAEMONCONNECTINGPORT]    Enter the daemon connecting port.
      --daemonSFTPPort[=DAEMONSFTPPORT]                Enter the daemon SFTP listening port.
      --daemonSFTPAlias[=DAEMONSFTPALIAS]              Enter the daemon SFTP alias.
      --daemonBase[=DAEMONBASE]                        Enter the base folder.
  -q, --quiet                                          Do not output any message
      --ansi|--no-ansi                                 Force (or disable --no-ansi) ANSI output
  -n, --no-interaction                                 Do not ask any interactive question
```

## Server Commands
### Bulk Power Actions

Perform bulk power management on large groupings of servers or nodes at once.
```sh
php artisan p:server:bulk-power [options] <action>
```

```sh
Arguments:
  action                 The action to perform (start, stop, restart, kill)

Options:
      --servers[=SERVERS]  A comma separated list of servers.
      --nodes[=NODES]      A comma separated list of nodes.
  -q, --quiet              Do not output any message
      --ansi|--no-ansi     Force (or disable --no-ansi) ANSI output
  -n, --no-interaction     Do not ask any interactive question
```

### Process Schedules

Process schedules in the database and determine which are ready to run. This runs every minute via the scheduler.
```sh
php artisan p:schedule:process
```

## Egg Commands
### Check for Egg Updates

Compares each egg against its update URL and reports whether it is up to date. Eggs without an update URL are skipped. This runs daily via the scheduler.
```sh
php artisan p:egg:check-updates
```

### Update Egg Index

Refreshes the cached index of available eggs from the Pelican CDN. This runs daily via the scheduler.
```sh
php artisan p:egg:update-index
```

### Normalize an Egg

Upgrades an egg json/yaml file to the latest format as yaml.
```sh
php artisan p:egg:normalize [options] <file>
```

```sh
Arguments:
  file                   Path to the egg json/yaml file.

Options:
      --delete-original  Delete the original file after converting.
  -q, --quiet            Do not output any message
      --ansi|--no-ansi   Force (or disable --no-ansi) ANSI output
  -n, --no-interaction   Do not ask any interactive question
```

## Maintenance Commands
### Prune Docker Images

Clean up all dangling docker images to clear up disk space. If no node ID is given, all nodes are cleaned. This runs daily via the scheduler.
```sh
php artisan p:maintenance:prune-images [<node>]
```

### Prune Orphaned Backups

Marks all backups older than "n" minutes that have not yet completed as being failed. Defaults to the `backups.prune_age` config value (360 minutes).
```sh
php artisan p:maintenance:prune-backups [options]
```

```sh
Options:
      --prune-age[=PRUNE-AGE]  Age in minutes after which an uncompleted backup is marked as failed.
  -q, --quiet                  Do not output any message
      --ansi|--no-ansi         Force (or disable --no-ansi) ANSI output
  -n, --no-interaction         Do not ask any interactive question
```

### Clean Service Backup Files

Clean orphaned .bak files created when modifying services. This runs daily via the scheduler.
```sh
php artisan p:maintenance:clean-service-backups
```

### Fix Database Grants

Re-issues the grants of all server databases so that their names are no longer used as wildcard patterns.
```sh
php artisan p:maintenance:fix-database-grants
```

## Migrations
### Migration Command
```sh
php artisan migrate [options]
```

```sh
Options:
      --database[=DATABASE]        The database connection to use
      --force                      Force the operation to run when in production
      --path[=PATH]                The path(s) to the migrations files to be executed (multiple values allowed)
      --realpath                   Indicate any provided migration file paths are pre-resolved absolute paths
      --schema-path[=SCHEMA-PATH]  The path to a schema dump file
      --pretend                    Dump the SQL queries that would be run
      --seed                       Indicates if the seed task should be re-run
      --seeder[=SEEDER]            The class name of the root seeder
      --step                       Force the migrations to be run so they can be rolled back individually
      --graceful                   Return a successful exit code even if an error occurs
      --isolated[=ISOLATED]        Do not run the command if another instance of the command is already running [default: false]
  -q, --quiet                      Do not output any message
      --ansi|--no-ansi       Force (or disable --no-ansi) ANSI output
  -n, --no-interaction             Do not ask any interactive question
```
### Running Migations
```sh
php artisan migrate
```

### Rollback previous Migration
```sh
php artisan migrate:rollback [options]
```

```sh
Options:
      --database[=DATABASE]  The database connection to use
      --force                Force the operation to run when in production
      --path[=PATH]          The path(s) to the migrations files to be executed (multiple values allowed)
      --realpath             Indicate any provided migration file paths are pre-resolved absolute paths
      --pretend              Dump the SQL queries that would be run
      --step[=STEP]          The number of migrations to be reverted
      --batch=BATCH          The batch of migrations (identified by their batch number) to be reverted
      --ansi|--no-ansi       Force (or disable --no-ansi) ANSI output
  -n, --no-interaction       Do not ask any interactive question
```

### Check Migration Status
```sh
php artisan migrate:status [options]
```
```sh
Options:
      --database[=DATABASE]  The database connection to use
      --pending[=PENDING]    Only list pending migrations [default: false]
      --path[=PATH]          The path(s) to the migrations files to use (multiple values allowed)
      --realpath             Indicate any provided migration file paths are pre-resolved absolute paths
      --ansi|--no-ansi       Force (or disable --no-ansi) ANSI output
  -n, --no-interaction       Do not ask any interactive question
```
Providing no extra options, `php artisan migrate:status`, You should see an output similar to the below
```sh title='Migration Status Output'

  2016_01_23_195641_add_allocations_table ............................................................ [1] Ran
  2016_01_23_195851_add_api_keys ..................................................................... [1] Ran
  ...
  ...
  2024_07_12_095213_fix_missing_sqlite_foreign_keys .................................................. [1] Ran
  2024_08_13_171337_fix_allocation_server_foreign_key ................................................ [2] Ran
```
If any show `PENDING` or `FAILED`. Open a support thread on our discord for further assistance.

## Clearing Cache

The below commands are helpful if you need to clear the config or application cache.

```sh
php artisan cache:clear # Clears application cache
```
```sh
php artisan config:clear # Clears configuration cache
```

:::note
`php artisan config:cache` is disabled in Pelican, and `php artisan optimize` skips config caching. Caching the config would stop plugin config files (`/plugins/config/*.php`) from loading.
:::
