Getting Started

What a Pelican server needs and the one-command install: requirements, the virtualization check, installing Docker, starting it on boot and enabling swap.

Pelican runs on a dedicated Linux server, and the recommended way to install it is with Docker. The quickest way there is the install script below; this page also covers getting Docker ready yourself, if you'd rather install the Panel step by step.

You should have some basic familiarity with Linux before you proceed!

Coming from Pterodactyl?

You don't need a fresh install. Follow Migrating from Pterodactyl to upgrade your existing Panel and keep all your data.

Requirements

Pelican runs on a wide range of operating systems, so pick whichever you are most comfortable using, as long as it supports Docker Engine.

Docker may not work under OpenVZ, Virtuozzo or LXC virtualization unless your provider has configured it for nested containers. kvm and bare metal (none) work without issues. To check what your server uses, run:

If that command isn't available, sudo dmidecode -s system-manufacturer usually tells you as well.

A domain (or subdomain) for the Panel, such as panel.example.com with an A record pointing at your server, gives it HTTPS. It's optional to start with: without one the Panel is served on your server's IP address, and you can add the domain later.

  • On CentOS Stream, AlmaLinux and Rocky Linux 10, xt_addrtype is missing, so Docker installs but won't start.
  • On Oracle Linux with its UEK kernel, xt_ipvs is missing, so Docker runs but Swarm can't reach its services (the Panel answers 502).

Enabling Swap

On most systems, Docker will be unable to setup swap space by default. You can confirm this by running docker info and looking for the output of WARNING: No swap limit support near the bottom.

Enabling swap is entirely optional, but we recommended doing it if you will be hosting for others and to prevent OOM errors.

To enable swap, open /etc/default/grub as a root user and find the line starting with GRUB_CMDLINE_LINUX_DEFAULT. Make sure the line includes swapaccount=1 somewhere inside the double-quotes.

After that, run sudo update-grub followed by sudo reboot to restart the server and have swap enabled. Below is an example of what the line should look like, do not copy this line verbatim. It often has additional OS-specific parameters.
